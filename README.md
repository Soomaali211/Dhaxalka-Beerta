# 🌿 Beerta & Dhaxalka — Nidaamka Xisaabinta Dhaxalka (Faraa'idka Shaaficiga) & GIS-ka Beeraha

**Beerta & Dhaxalka** waa nidaam dhammaystiran oo isku dara **Xisaabinta Dhaxalka Shareecada Islaamka (Mad-habta Shaaficiga)** iyo **Naqshadaynta / Qaybinta Khariidadaha Dhulka iyo Beeraha (GIS Land Subdivision)**. Waxaa loogu talagalay in si hufan, cadaalad ah, oo leh daliillo sharci iyo khariidad rasmi ah loogu qaybiyo dhaxalka lacagta, hantida, beeraha, iyo jagooyinka (plots).

## ✨ Astaamaha Muhiimka ah ee Nidaamka

### 1. ⚖️ Xisaabinta Dhaxalka Shareecada (Mad-habta Shaaficiga)
- **Xisaabinta Rasmiga ah ee Tarakada:** Waxay si toos ah u kala saartaa Hantida Guud (*Gross Estate*), Kharashka Aaska, Deymaha lagu leeyahay marxuumka, iyo Dardaaranka (*Wasiyyah* — xadka sharciga ah ee `≤ 1/3`), ka hor inta aan la qaybin hantida saafiga ah.
- **Xeerarka Faraa'idka oo Dhammaystiran:** Asxaabul-Furuudka, Casabada (*Asabah*), Xجب (*Al-Hajb* — reebista tooska ah iyo dhinaanta), Cawl (*Al-Awl*), Radd (*Ar-Radd*), iyo kiisaska gaarka ah sida *Al-Akdariyyah*, *Al-Mushtarakah*, iyo *Awoowga & Walaalaha*.
- **Daliillada Shareecada:** Dhaxle kasta wuxuu wataa sababta saamigiisa iyo daliilka Qur'aanka Kariimka iyo Xadiiska.

### 2. 🗺️ Saddexda (3) Hab ee Qaybinta Plots-ka & Beeraha
Nidaamku wuxuu bixiyaa saddex hab oo kala duwan oo loo qaybiyo jagooyinka/plots-ka dhulka:
1. **Saami Sax ah + Plots Wadaag ah (`Exact Faraid + Shared Plots`):**
   - Dhaxle kasta wuxuu qaadanayaa saamigiisa saxda ah ee Faraa'idka; plots-ka jajabka noqda waxaa si sax ah u wadaagaya dhaxlayaasha ku leh jajabka.
2. **Wadaag La'aan — Plot kasta 1 Qof (`No Shared Plots`):**
   - Ma jiro hal plot oo laba dhaxle wadaagayaan. Plot kasta hal dhaxle oo keliya ayaa loo qoondeeyaa, farqiga yarna waxaa lagu dheellitiraa xisaabta qiimaha/lacagta si cadaaladdu u sugnaato.
3. **Tiro Siman — Laga Reebo Half-Plots & Jajabka (`Equal Whole Plots — No Half-Plots or Fractions`):**
   - Waxaa gebi ahaanba meesha laga saarayaa *half-plots* iyo jajabka. Dhaxlayaasha isku darajada ah waxay qaadanayaan tiro plots ah oo siman oo dhammaystiran, plots-ka soo hadhana waxaa loo kaydiyaa *Kayd Qoys / Hanti Wadaag ( ama iib lagu qaybsado saamiga sharciga ah)*.

### 3. 🎨 Midab u Gaar ah Dhaxle Kasta (Unique Heir Colors)
- Dhaxle kasta oo kiiska ku jira wuxuu leeyahay **midab u gaar ah** oo aan lala wadaagin.
- Midabkaas wuxuu si isku mid ah uga muuqanayaa **Khariidadda GIS**, **Shaxda Natiijada**, **Legend-ka Dhaxlayaasha**, iyo **Warbixinta / Khariidadda PDF-ka**.

### 4. 🧭 Khariidadda GIS, GPS-ka Tooska ah & Naqshadaynta Beeraha
- **Badhanka GPS Current Location & Zoom Active Layer:**
  - Badhanka **GPS-ka** wuxuu ku tusayaa barta saxda ah ee aad xilligaas ku sugan tahay.
  - Badhanka **Zoom Active Layer** wuxuu si toos ah kuugu soo dhoweynayaa xudduudda beerta ama dhulka aad ka shaqaynayso.
- **Naqshadaynta Tooska ah (Subdivision Engine):** Qaybinta tooska ah ee *Blocks* (sida `90m × 48m`) iyo *Plots*, waddooyinka gudaha, xagasha wareegga (`0°–180°`), goobaha **Danguud** (masjid, ceel, dugsi, waddo), aagagga qiimaha (**Zones A–D**), iyo heerarka dhulka (**Tiers H1–H3**).
- **Faylasha GIS ee la taageero:** Soo gelinta (*Import*) iyo dhoofinta (*Export*) faylasha `GeoJSON`, `KML`, `KMZ`, `Shapefile (.zip)`, `CSV`, iyo `Excel (.xlsx)`.

### 5. 🖨️ Daabacaadda Khariidadda PDF & Shahaadada Dhaxalka
- **Daabacaadda Khariidadda Rasmiga ah (Cartographic PDF Composer):** Waxaad PDF ahaan ugu daabici kartaa khariidadda sida dhaxalka loo kala helay iyadoo leh:
  - **Cinwaanka Khariidadda (Title)**
  - **Legend-ka Dhaxlayaasha, Midabbadooda & Plots-ka ay heleen**
  - **Jihada Waqooyi (North Arrow)**
  - **Cabirka Miisaanka Khariidadda (Scale Bar)**
  - **Xogta Isha & Taariikhda (Source Information)**
  - **Habaynta Bogga (Page Layout — A4/A3, Portrait/Landscape)**
- **Shahaadada Rasmiga ah & Backup:** Daabacaadda warbixinta dhaxalka oo dhammaystiran iyo kaydinta kiisaska badan (*Saved Cases & JSON Backup/Restore*).

### 6. 📡 Shaqaynta Offline-ka (Offline Mode)
- Marka lagu rakibo telefoonka Android (`APK` ama `PWA`), xisaabinta dhaxalka, kiisaska kaydsan, iyo naqshadda vector-ka GIS waxay u shaqeeyaan si buuxda xitaa marka aan khadka internet-ku jirin.

## 💻 Ku-Shaqaynta Kombiyuutarka (Local Development)

Haddii aad rabto inaad koodhka ku kiciso kombiyuutarkaaga:

```bash
# 1. Rakib packages-ka
npm install

# 2. Daar server-ka horumarinta (Port 3000)
npm run dev

# 3. Hubi imtixaannada xisaabta Faraa'idka & TypeScript
npm test
npm run lint

# 4. Dhis Web App-ka
npm run build

# 5. Dhis Android Signed APK oo dhig bogga hore (u baahan JDK 21 + Android SDK)
npm run apk:build
```
